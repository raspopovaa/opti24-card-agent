# Справочники API: статусы, виды топлива, регионы, АЗС

Справочники приходят из API бесплатно. Здесь их смысл и ловушки; сами списки агент берёт
инструментом `lookup_dictionary`, а виды топлива переводит в ID по каталогу в коде.

## Что значат статусы карты

Статус карты — код справочника CardStatus с русским названием: Active «Активна»,
Locked(Client) «Заблокирована (Клиент)» — заблокировал сам клиент, Locked(Manager)
«Заблокирована (ГПН-КП)» — заблокировал менеджер оператора, Locked(SB) «Заблокирована (СБ)» —
служба безопасности, Locked(GL) «Заблокирована (ГЛ)», Inactive «Неактивна», Reserved
«Зарезервирована», Lost/Broken «Утеряна/Испорчена», Returned «Возвращена», Expects Transfer
«Ожидание переноса», Transferred «Перенесена». Блокировку Locked(Client) поставил сам клиент;
причину блокировок менеджера, СБ и ГЛ уточняют у менеджера оператора. В справочнике часть
кодов встречается дважды: действует запись с active=true.

## Статусы договора

ContractStatus: Active «Активен», Not Active «Не активен», ManualLock «Заблокирован вручную»,
Auto Blocked «Заблокирован автоматически», Blocked SB «Заблокирован СБ», Closed «Закрыт»,
Auto-Closed. Статусы Gas Working, Gas Not Working и GS technical record относятся к АЗС.

## Почему у вида топлива два разных ID

У вида топлива в API два ID без общего ключа. В лимитах, товарных ограничителях и операциях —
ID группы продукта (ProductGroup), например ДТ 1-CK237, АИ-92 1-CK235, АИ-95 1-CK234; категория
всего топлива — 1-CK231 «Топливо» (ProductType). В ценах АЗС, фильтрах АЗС и проверке покупки —
14-значный код Goods: ДТ 00000000000006, АИ-92 00000000000004, АИ-95 00000000000003. Лимит на
1-CK231 ограничивает всё топливо, на 1-CK237 — только ДТ. У части видов (ДТ Зимнее, ДТ ОПТИ,
АИ-92 ОПТИ, АИ-95 ОПТИ, АИ-93, AdBlue) есть цена на АЗС, но нет отдельной группы для лимита.

## Коды регионов в региональных ограничениях

Регион в ограничениях и в данных АЗС — ID справочника Region. У регионов России это код
оператора, а не код ГИБДД: 50 — Новосибирская область, 46 — Московская область, 7110 — ХМАО,
7114 — ЯНАО. У Беларуси коды вида BY-HO. Поэтому регион называют по названию из справочника,
а не по номеру на автомобиле.

## Какие бывают АЗС и чьи они

Принадлежность АЗС (OwnType): Газпромнефть, ОПТИ 24, Франчайзинг Газпромнефть, Франчайзинг
ОПТИ, Партнёр, Аренда. Тип точки (POIType): АЗС, АЗС H2H (партнёрская АЗС с подключением
host-to-host к процессингу), ААЗС (автоматическая), АГНКС (газ), мойка, шиномонтаж, сервис,
стоянка, отель, дорожный комплекс. Около двух третей точек в сети — партнёрские. Цены в данных АЗС есть
примерно у трети точек.

## Чем можно оплатить на АЗС

Способы оплаты в данных АЗС: Plastic — пластиковая карта, OCR — показать QR-код, LKP —
сканировать QR-код, LKK — онлайн-оплата, TMB — по номеру топливной карты, NFC. Если у АЗС нет
нужного способа, оплата этим способом там не пройдёт.

## Схемы оплаты и расчёта скидки договора

Схема оплаты (PaymentScheme) — например «7+7», «15+15», «30+15» для постоплаты или «Без
выставления счетов» для предоплаты и постоплаты. Условие оплаты (PaymentTerm): предоплата или
постоплата. Схема скидки (DiscountScheme): «Текущий месяц», «Предыдущий месяц» — объём для
скидки берётся из этого месяца — или «Индивидуальная».

## Офисы продаж и заказ карт

Новые пластиковые карты заказывают с указанием офиса продаж (справочник Office): у офиса есть
адрес, телефон, email и график работы. Заказ карт в этой версии агента не поддерживается:
агент предлагает личный кабинет или менеджера.
