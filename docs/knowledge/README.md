# База знаний по договору топливных карт

Агент отвечает на вопросы о договоре — цены и скидки, сервисный сбор, блокировка и отказ,
оплата, документы, претензии, расторжение, тарифы API — инструментом `lookup_knowledge`.
Инструмент бесплатный и ищет только по выжимкам в этой папке. API оператора он не вызывает.

| Файл | О чём |
|---|---|
| `pricing.md` | цена топлива, скидки по сетям и регионам, сервисный сбор, изменение условий |
| `card-service.md` | выпуск и замена карт, блокировка, причины отказа в обслуживании |
| `contract-support.md` | пополнение счёта, закрывающие документы, претензии, расторжение, возврат аванса |
| `api-access.md` | тарифы API и что будет, когда пакет запросов закончится |
| `sources.json` | реестр документов оператора, из которых сделаны выжимки, и хеш учтённой версии |

## Правила выжимок

- В каждом файле в заголовке указаны `sources` (ID из `sources.json`), `edition` (редакция
  документа) и `checked` (дата сверки). Тест `test_every_summary_names_its_source_and_edition`
  не даёт их потерять.
- Пишите своими словами коротко и со ссылкой на пункт договора. Большие фрагменты не копируйте.
- Разделы начинаются с `## `: по ним ищет `lookup_knowledge`. Называйте раздел так, как
  клиент задаёт вопрос («…и возврат аванса»), иначе поиск его не найдёт.
- Выжимки описывают типовую редакцию. Условия конкретного клиента могут отличаться, и агент
  говорит об этом в ответе.

## Как держать базу актуальной

Сайт opti-24.ru отдаёт документы только браузеру человека. Скрипты, CI и автоматические
браузеры получают ошибку 403. Обходить эту защиту нельзя, поэтому обновление полуавтоматическое:

1. Раз в месяц, в начале отчётного периода, скачайте в браузере документы из `sources.json`.
   У каждого указан `url` или раздел сайта (`site_section`). Сохраните их в `~/Downloads` или в
   папку входящих.
2. Запустите проверку:

   ```bash
   python scripts/sync_knowledge.py --inbox ~/Downloads
   ```

   Скрипт найдёт файлы по шаблонам имени и сравнит хеш с учтённой версией. Для новых и
   изменившихся документов он перечислит выжимки, которые нужно пересмотреть. Код выхода 1
   означает, что есть изменения.
3. Обновите выжимки, поменяйте `edition` и `checked`, прогоните `pytest` и зафиксируйте версию:

   ```bash
   python scripts/sync_knowledge.py --inbox ~/Downloads --accept supply-offer
   ```

4. Проведите изменения через PR: это цены и юридические условия, их проверяет человек.

Оператор обязан уведомлять об изменении условий на сайте, в личном кабинете или по email
(Приложение № 1 к договору, п. 4 и 6). Такое уведомление — тоже повод запустить проверку
вне графика.

Ещё не загружены: Приложение № 4 «Инструкция по использованию Карты» (вероятно, там коды
отказа), Приложение № 2 о товарных ограничителях, Приложение № 12 «Перечень сервисных услуг»
и перечень АЗС тарифа Drive.
