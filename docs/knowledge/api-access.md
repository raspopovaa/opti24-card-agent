# Доступ к API: тарифы и пакет запросов

## Тарифы API

| Тариф | Цена за месяц с НДС | Пакет запросов |
|---|---|---|
| Free | входит в сервисные услуги договора поставки | 500 |
| Base | 20 000 ₽ | 10 000 |
| Advanced | 50 000 ₽ | 50 000 |
| Profi | 150 000 ₽ | без ограничений |
| Over (дополнительный) | 10 000 ₽ | 10 000 |

Отчётный период — календарный месяц. Сразу после подключения действует тариф Free (оферта API,
п. 4.3). Тарифицируемый тариф выбирают в личном кабинете и оплачивают полной предоплатой; без оплаты
действует Free (п. 4.4).

## Что будет, когда пакет закончится

- Когда пакет запросов исчерпан, доступ к API приостанавливается до конца месяца (тарифы, п. 4.4
  оферты API).
- На Free продолжить работу можно, только выбрав и оплатив другой тариф (п. 4.3).
- Пакет Over подключается только к Base и Advanced; к Free и Profi его подключить нельзя.
- Число запросов определяется только по статистике оператора.
- Какие методы тарифицируются, указано в спецификации API: тарифицируемые и бесплатные методы
  перечислены в `specifications/api-methods.yaml` SDK `apisdkopti24`.
